
# ✈️ AeroWise

### Smarter Flights. Better Journeys.

AeroWise is an AI-powered airline booking and flight recommendation platform designed to help travellers find the most suitable flight itineraries based on their individual preferences.

Instead of simply displaying flights based on price, AeroWise aims to optimize complete journeys by considering ticket prices, travel duration, stopovers, airline quality and user preferences.

## 🎯 Problem Statement

Traditional flight booking platforms primarily allow users to filter and sort available flights. Finding the best combination of connecting flights based on multiple constraints can still be challenging.

AeroWise aims to solve this through intelligent flight recommendations and multi-objective optimization.

## 🚀 Key Features

### Flight Booking
- Search flights between airports.
- Compare airlines and ticket prices.
- Explore direct and connecting flights.
- Passenger management and booking confirmation.

### AI-Powered Recommendations
- Personalized flight recommendations.
- Cheapest, fastest and best-balanced itineraries.
- Intelligent stopover recommendations.
- Multi-objective flight optimization.

### Predictive Analytics
- Flight price prediction.
- Flight delay probability estimation.
- Historical price analysis.
- Potentially cheaper travel-date suggestions.

### Travel Assistant
- Natural-language flight search.
- Personalized travel suggestions.
- Explanation of AI recommendations.

## 🏗️ Architecture

The application follows a modular architecture:

- Client: React-based user interface.
- Server: Express backend handling business logic and bookings.
- AI-Service: Python service for predictions, recommendations and optimization.
- Database: MongoDB for application data.
